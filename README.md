# Daily Stack — To-Do List App

A clean, responsive to-do list web app built from scratch using vanilla HTML, CSS, and JavaScript — no frameworks or libraries.

## 🔗 Live Demo
https://YOUR-USERNAME.github.io/todo-app/

## ✨ Features
- Add, complete, and delete tasks
- Persistent storage using `localStorage` — tasks survive page refresh
- Live task counter ("3 tasks remaining", "All tasks completed!")
- Clear completed tasks in one click
- Light / dark mode toggle (saved across sessions)
- Landing page with a loading animation before entering the app
- Celebration screen when all tasks are completed
- Fully responsive — works on mobile, tablet, and desktop

## 🛠 Built With
- HTML5
- CSS3 (custom properties, Flexbox, responsive design with `clamp()` and media queries)
- Vanilla JavaScript (DOM manipulation, event delegation, localStorage)
